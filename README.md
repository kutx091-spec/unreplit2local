## Quick Start

### Prerequisites

- Node.js 18+ and pnpm installed

### Run the app

**Mac/Linux:**
```bash
chmod +x run.sh
./run.sh
```

**Windows:**
```
run.bat
```

This project contains multiple services. `run.sh` and `run.bat` start them in parallel.

To start them manually:
```bash
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/mockup-sandbox run dev
pnpm --filter @workspace/replit-to-local run dev
```

## Environment Variables

## ⚠️  Database Required

This project needs a PostgreSQL database. Set up a local Postgres instance or use a free hosted service like [Neon](https://neon.tech) or [Supabase](https://supabase.com), then add the connection URL to your `.env`:

```
DATABASE_URL=postgresql://user:password@host:5432/dbname
```
